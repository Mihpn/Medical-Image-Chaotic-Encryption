# 🔐 Medical Image Chaotic Encryption

Ứng dụng hệ hỗn loạn (Chaotic System) vào mã hóa ảnh y tế nhằm tăng cường bảo mật dữ liệu hình ảnh.
Project tập trung vào việc xây dựng thuật toán mã hóa dựa trên Chaos Theory và đánh giá độ an toàn thông qua các phép đo thống kê.

---

## 📖 Overview

Medical Image Chaotic Encryption là đồ án nghiên cứu sử dụng các hệ động lực học hỗn loạn
để tạo ra chuỗi pseudo-random phục vụ cho quá trình:

- Encryption (Mã hóa ảnh)
- Decryption (Giải mã ảnh)
- Salt & Diffusion
- Correlation Analysis
- Security Evaluation

Mục tiêu chính:

- Giảm correlation giữa các pixel
- Tăng entropy của ảnh mã hóa
- Bảo vệ dữ liệu ảnh y tế trước các phương pháp phân tích thống kê
